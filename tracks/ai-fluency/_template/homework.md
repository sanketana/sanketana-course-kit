# Homework — Lesson 2

## 1. Three rounds on something real

Pick a task you actually need this week. Run three rounds as in class, logging your prediction each time
in `assets/prompt-log-study-plan.md` (copy it and rename).

## 2. Judge a stranger's prompt

In `assets/homework-prompt.md` there's a prompt someone else wrote. Before reading the output, write what
it will get wrong. Then read the output. Score yourself.

## 3. Stretch — write the standard first

For any task, write your three-line standard *before* writing the prompt. Does the prompt come out differently?
