# Teacher notes — Lesson 3

## Prep

- Run `predict_decisions.py` yourself once. Know which line trips students (line 3).
- Have `starter_battery.py` open in a second tab before class.

## Timing

If the student nails the prediction block in under 8 minutes, skip straight to the build and
use the spare time on the stretch homework live.

## Common Pitfalls

- Writing `if battery > 50` for "50 or above". Ask them to test with exactly 50.
- Forgetting the colon. Let the error appear; don't pre-empt it.
- Indenting the `else` under the `if` body. Show how VS Code's guide lines help.

## What to Watch For

A student who predicts correctly but can't explain *why* hasn't got the mental model yet.
Ask them to narrate the program line by line for the value 50.
