# Formative 1 — marking notes

TEACHER-ONLY. The answers themselves are in `formative-1.yaml`; this file is for the part a
machine can't do — what a `short` answer has to contain, what a wrong answer tells you, and
what to re-teach because of it.

Number these to match the question ids. Only questions that need judgment need an entry;
a `single` question with an obvious right answer does not.

## q3

**Full marks:** names a boundary value (20 or 49) *and* says why — the middle of a range
doesn't find an off-by-one.

**Half marks:** names the right values with no reason, or gives the reason without naming a
value. Both are worth a follow-up question rather than a mark.

**No marks:** "I'd test 35" — testing the middle is exactly the habit this question is
checking for.

**If they get this wrong:** re-run the battery build from l03 and stop at the boundary test.
Five minutes, and it's the one habit from that lesson that transfers.
